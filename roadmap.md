# NetDevOps Engineer Roadmap
**Start Date:** April 28, 2025  
**End Date:** October 31, 2025  

## 🔥 Objective
To become a job-ready NetDevOps Engineer by combining networking certifications (CCNA, AZ-900) with hands-on projects involving automation, infrastructure as code, monitoring, and cloud-native technologies.

---

## 🗓️ Monthly Timeline Overview

### ✅ April – May: Foundation Phase
- Study CCNA: Networking basics, subnetting, routing, VLANs
- Learn Ansible and Python (Netmiko) for basic automation
- Set up Cisco Modeling Labs (CML) and practice real device configuration
- Mini Project: Automate hostname/IP configs on 3-router lab

### ✅ June: Automation Phase
- Build more advanced Ansible playbooks (VLANs, OSPF)
- Automate config backups using Python + Netmiko
- Begin studying AZ-900 cloud concepts
- Mini Project: GitHub-pushed config backups

### ✅ July: Cloud Networking + Terraform
- Finish AZ-900 study + take exam
- Manually deploy VNets, NSGs, and subnets in Azure
- Use Terraform to automate cloud infra
- Mini Project: Terraform script to deploy complete Azure VNet

### ✅ August: Monitoring + Docker + GitHub
- Learn Docker: containers, images, Dockerfiles
- Install Grafana + InfluxDB for home network monitoring
- Build GitHub repos + documentation
- Mini Projects:
  - Dockerize the ticketing app
  - Grafana SNMP dashboard

### ✅ September: CI/CD + Kubernetes
- Learn Kubernetes fundamentals using Minikube
- Deploy containerized apps (your ticketing app)
- Learn Helm, config maps, secrets, service types
- Create GitHub Actions CI/CD pipeline
- Mini Projects:
  - Deploy ticketing app in Kubernetes
  - GitHub Action: config auto-push to routers

### ✅ October: Final Projects + Launch
- Build and polish your React portfolio website
- Publish all projects, write blog-style READMEs
- Final CCNA study + exam attempt
- Project: Deploy AI agent to assist with network CLI troubleshooting
